# Security and responsible disclosure

This repository is a public IMPERIAL Core documentation/reference surface. It is not a claim of live protection, a certified production service, or a channel for customer secrets.

**Do not submit API keys, access tokens, passwords, recovery codes, private repositories, or undisclosed vulnerabilities to public issues or pull requests.** Use GitHub private vulnerability reporting if it is enabled for this repository; otherwise establish an owner-approved private channel before sharing sensitive details.

Design requirements: Zero Trust, Deny by Default, Fail Closed, bounded agent permissions and independent verification. Current implementation status must be read from [README.md](README.md) and its exact evidence links.

The maintainer must validate scope, affected revision, reproduction and remediation before asserting a fix. No bug bounty, SLA or security certification is implied.
